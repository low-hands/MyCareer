# 105 · Agent 检查清单

> 本文件从本地 `docs/iteration/105-agent-checklist.md` 复制而来，供其他机器查看；文中提到的 096、100、103、104 等迭代记录只保存在本地。

按 agent 的组成部分列出要关注和检查的点。`[x]` 表示本分支已处理，`[ ]` 表示待做。

## 上下文

- [x] 新会话不提供 `read_conversation_span`（offered、schema、`available_now` 三者一致）
- [ ] 依赖上文的追问（"帮我看一下"）：预加载只看当前一句，评估追问频率与模型自行补救的成功率，再决定是否结合历史改写查询
- [ ] 量一下主 agent system prompt 的长度，以及其中只在特定场景使用的规则

## 决策

- [ ] 选择是否正确：最终选中的工具，而不只是"工具是否被提供"
- [ ] 该问、该做、还是该结束：`ask_user` 比例；"本该做却问了""本该问却做了"的样本
- [ ] 观察结果是否改变下一步：同一请求、不同工具结果，后续动作是否相应变化
- [ ] 参数接地：参数校验失败、编造 ID、调用未提供工具被拒的频率
- [ ] 稳定性：关键场景跑 k 次，统计 pass^k

## 规划

- [ ] 主 agent 没有持久化计划，多步任务靠每一步临场判断；评估 3 步以上任务的完成率与步数分布
- [ ] 是否引入持久化计划、由 harness 推进、模型只在关键节点介入：先单独讨论设计

## 工具

- [x] 检索改用业界基线（例句并入文档、去掉证据门槛、RRF），见 100
- [x] 自动预加载过滤停用词
- [x] 岗位调研子 agent 只挂载自己的 skill；prompt 与 skill 分离
- [ ] 英文复数规则不处理 -ies（`replies` → `replie`）
- [ ] `loaded_capabilities` 只增不减：有上限，暂不处理；若长对话质量受影响再设上限

## 记忆

- [ ] 情景记忆补向量：先把 `episode_retrieval` 的未召回用例分类，扩充并冻结评估集（换说法、同行业干扰项、本该找不到），再做混合检索；复用事实记忆的 SQLite 向量存储与删除同步
- [ ] 防止向量检索在"本该找不到"时乱返回：设相似度阈值，单独评估
- [ ] 事实记忆 `search_career_memory` 工具路径接上已有的混合检索
- [ ] 时间表达：先测量自动投影是否因此出错；确有需要再用现成的时间解析库，不手写正则
- [ ] 公司别名（ByteDance / 字节、PDD / 拼多多）：别名表，事实、情景、岗位库共用

## 执行与安全护栏

- [x] 审批策略由 `destructive` / `external_write` 推导；外部与不可撤销操作强制确认；轻量写操作补撤销
- [ ] 提示词注入 × 写操作默认自动执行：在 JD、邮件、调研网页、简历中埋指令的红队用例，断言不触发写操作
- [ ] 日历外部写入的故障恢复：中断、响应丢失、重复提交
- [ ] 数据外发清单（主模型、embedding、网页调研各收到什么）；删除一条记忆，端到端确认向量、缓存、checkpoint、trace、备份都清掉
- [ ] 新增写工具时必须回答 `destructive` 判定；`sync_application_emails` 接入自动应用 worker 时重审

## 人机协作

- [x] 三类确认文案；撤销入口与回执
- [ ] 跨轮次续接：待确认操作、问卷、做到一半的任务，插入无关话题后能否接上

## 延迟

已知（本地 trace，2026-09-05 至 09-29，187 个含决策的轮次，早于本分支改动）：每轮墙钟 p50 约 24 秒、p90 约 156 秒；每轮主模型决策调用 p50 2 次、p90 4 次，单次决策 p50 约 8 秒、p90 约 34 秒；调用专项模型的轮次，其专项调用合计 p50 约 107 秒。

- [ ] 用当前分支重新统计延迟分布（按阶段：决策、专项 worker、embedding、工具执行、摘要压缩）
- [ ] 每轮决策调用次数：区分正常多步与重试、重新提示、被拒后重选
- [ ] 流式输出与进度提示：长任务（调研、定制、模拟面试规划）期间用户能看到进展
- [ ] 长任务后台化：专项 worker 不阻塞对话轮次，完成后通知
- [ ] 能并行的步骤并行（如多个岗位分析、逐题评估已并行）
- [ ] 小模型 / 快模型分担轻量环节（意图路由、输入分类、摘要）
- [ ] 提示词缓存命中率：前缀稳定性、`cache_hit_ratio` 汇总
- [ ] 意图预加载的 embedding 调用：复用查询向量，测其增加的延迟
- [ ] 超时与预算：每类调用的超时是否合理，超时后的降级路径

- [ ] `responses` 协议下的思考模式：共享函数只在 `chat_completions` 下关闭 Qwen 思考
- [ ] 每个模型的结构化输出成功率、重试率、空响应率
- [ ] 切换或新增模型时的检查流程：轨迹回放、pass^k、成本与延迟对比
