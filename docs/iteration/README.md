# 能力迭代记录

此目录记录 Career Agent 各项能力从假设、设计、实现到验证的迭代过程。架构选型与长期边界见 [架构选型决策](../architecture/CAREER_AGENT_ARCHITECTURE_SELECTION.md)。

## 记录原则

- 每项能力独立建档，避免把不同能力的决策、实验和问题混在同一份文档中。
- 每次迭代记录目标、变更、验证证据、结果和下一步，而不仅记录最终结论。
- 业务状态、测试结果和可观测数据优先于主观判断。
- 涉及简历、邮箱、日历、投递或外部账户的迭代，必须记录数据范围、权限边界和审批行为。
- 不在文档中写入简历原文、邮件正文、访问令牌或其他敏感信息；使用脱敏样例或引用受控 Artifact。

## 文件命名

每个能力使用一个 Markdown 文件，文件名采用：

```text
NNN-能力名称.md
```

示例：

```text
001-career-profile.md
002-job-discovery.md
003-resume-tailoring.md
004-company-research.md
005-interview-coaching.md
006-application-tracking.md
```

`NNN` 按创建顺序递增，不因能力优先级变化而重排。
